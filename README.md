# Installation:
- Cliquer sur le bouton vers <> Code
- Copier l'url
- Se positionner dans le dossier de votre choix
- Ouvrir un terminal et lancer la commande:

  `git clone <lien copié>`
  Ceci va cloner les fichiers nécessaires dans votre dossier actuel.

# Usage:
- Ouvrir le dossier que vous venez de cloner
- Ouvrir la page index.html depuis le navigateur de votre choix
